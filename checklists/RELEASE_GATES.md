# Release gates

A public metric/API endpoint must pass:

- [ ] source rights known
- [ ] all input observations traceable
- [ ] input freshness passes
- [ ] no missing value silently coerced to zero
- [ ] units normalized
- [ ] entity joins meet confidence threshold
- [ ] transform version stored
- [ ] Jev spec has eval fixtures if used
- [ ] limitations returned
- [ ] revised source data handled
- [ ] public output does not expose INTERNAL_ONLY parents
- [ ] endpoint remains objective POW state, not personalized Muse decision
